# Splunk labs
This repository contains hands‑on Splunk investigations, threat‑hunting exercises, and incident response writeups focused on log analysis, detection engineering, and practical SIEM use.
Each lab is self‑contained and follows a reproducible documentation template so the work is sharable, teachable, and safe to publish.
